# Service Desk — система учёта заявок в техподдержку

Практическая работа 2 по учебной практике: списки, поиск, фильтрация и
пагинация на Flutter Web.

Студент: Казиахмедов Р. Р., группа П-1-23.

## Что это

Клиент службы технической поддержки. Данные хранятся в памяти — сервер
подключается позже, в ПР4. Реализованы два раздела:

* **Заявки** — регистрационный номер, тема, категория, приоритет, статус,
  исполнитель, заявитель, дата создания и срок решения по SLA;
* **Сотрудники поддержки** — ФИО, должность, отдел, линия поддержки,
  контакты.

## Возможности

* поиск по номеру и теме заявки (для сотрудников — по фамилии и отделу)
  с задержкой 350 мс после окончания ввода;
* фильтрация по категории, приоритету, статусу, исполнителю и диапазону дат
  создания — фильтры комбинируются между собой и с поиском;
* сортировка по щелчку на заголовке колонки с переключением направления;
* постраничный вывод с размером страницы 10, 25 или 50;
* множественное выделение строк и удаление выбранных с подтверждением;
* логическое и физическое удаление, показ удалённых записей и восстановление;
* адаптивная раскладка: до 600 пикселей — карточки и нижняя панель навигации,
  шире — таблица и боковая полоса;
* **все условия отбора отражаются в адресе страницы**, поэтому ссылку на
  отфильтрованный список можно открыть в новой вкладке или отправить коллеге.

Пример адреса:

```
/tickets?search=принтер&categoryId=5&priority=high&sort=dueAt,asc&page=2&size=25
```

## Запуск

```bash
flutter pub get
flutter run -d chrome --web-port=5555
```

Порт задан явно: по умолчанию `flutter run` выбирает случайный, и адрес
источника меняется от запуска к запуску.

Проверки:

```bash
flutter analyze
flutter test
flutter build web
```

Границы слоёв: виджет обращается к данным только через notifier, notifier не
знает про `BuildContext` и виджеты, модель не знает ни про кого. Интерфейс
репозитория объявлен отдельно от реализации, чтобы в ПР4 подменить
`InMemoryTicketRepository` на реализацию поверх API, не трогая экраны.

## Состояние «ошибка»

Данные лежат в памяти, отказать самому по себе тут нечему, поэтому в панель
инструментов вынесена кнопка со значком жучка: она включает учебный сбой
хранилища, и следующий запрос завершается исключением. Так проверяется
обработка состояния ошибки.
